# Voxcode

**화면을 보지 않고 여러 Claude Code 세션을 목소리로 지휘하는 비서입니다.**

- 작업이 끝나면 "**번개장터 봇, 가격 필터를 추가했습니다**"처럼 프로젝트 이름과 요약을 읽어 줍니다.
- "**자비스**" 하고 부른 뒤 말하면, 어느 프로젝트에 하는 말인지 판단해 그 세션에 전달합니다.

다른 일을 하면서 여러 프로젝트를 돌리는 사람을 위한 도구입니다. 눈이 불편한 사람의 접근성 도구로도 쓸 수 있습니다.
(경위: [`docs/decisions.md`](docs/decisions.md) 2026-09-26)

GitHub: https://github.com/PHM820/Voxcode (구 이름: eyes-free-coding)

---

## 무엇을 더하나

Claude Code에는 이미 공식 [스크린리더 모드](https://code.claude.com/docs/en/accessibility)(`--ax-screen-reader`)와 터미널 벨 알림이 있습니다.
Voxcode는 그것을 다시 만들지 않고, 훅(hook)으로 위에 얹어 두 가지만 더합니다.

| 기능 | 하는 일 |
|---|---|
| 완료 음성 요약 (TTS) | 세션이 끝날 때마다 "{프로젝트}, {요약}"을 읽어 줍니다. 여러 개가 동시에 끝나면 순서대로 읽습니다. |
| 음성 명령 (STT) | 호출어 → 받아쓰기 → 대상 판단 → 해당 세션에 전달. 모든 판단은 먼저 `~/.voxcode/log.jsonl`에 기록합니다. |

## 준비물

- Windows (macOS·Linux는 아직 지원하지 않음)
- Python 3.12 이상
- Node.js (세션에 말을 넣는 `voice/inject.js`용)
- 마이크 (음성 명령을 쓸 때)

> 설치와 처음 설정은 글자로 진행되므로 화면 확인이 필요합니다. 스크린리더(NVDA 등)나 다른 사람의 도움을 받아 진행하세요. "화면 없이"는 설정이 끝난 뒤부터입니다.

## 설치 (처음 한 번)

**1. 설치 스크립트 실행** — 프로젝트 폴더에서:

```
setup.cmd
```

가상환경(`.venv`), 패키지, 받아쓰기 모델(약 147MB), 기본 영어 음성 모델(약 64MB)을 받습니다.
SSL 인증서 오류(`CERTIFICATE_VERIFY_FAILED`)가 나면 백신의 SSL 검사 때문일 가능성이 높습니다 → [known-issues 1번](docs/known-issues.md#1-pip-ssl-인증서-검증-실패-백신-ssl-검사-소프트웨어-사용자-전원-영향-가능).

**2. 설치 확인**

```
.claude\verify.cmd
```

`ALL CHECKS PASSED`가 나오면 됩니다.

**3. 호출어 녹음** (음성 명령을 쓸 때만) — 같은 폴더의 터미널에서:

```
.venv\Scripts\python.exe -m voice.wakeword onboard
```

안내가 나올 때마다 Enter를 누르고 "자비스"라고 말합니다(2초씩 4번). 다른 호출어를 쓰려면 명령 끝에 붙이세요.
녹음하지 않아도 완료 음성 요약은 동작합니다.

**4. (선택) Jev 키 넣기** — 아래 [명령 판단 (Jev)](#명령-판단-jev) 참고.

## 켜고 끄기

Claude Code의 **아무 프로젝트 세션에서나**:
(`setup.cmd`가 두 명령을 사용자 전역 스킬 `~/.claude/skills/`에 연결해 둡니다. 연결을 지우려면 `.venv\Scripts\python.exe -m voice.control uninstall-skills`, Voxcode 폴더를 옮겼으면 새 위치에서 `install-skills`를 다시 실행하세요.)

| 명령 | 하는 일 |
|---|---|
| `/voice-on` | 켭니다. 처음이면 언어와 목소리를 고릅니다. |
| `/voice-off` | 끕니다. |

`/voice-on`이 하는 일:
1. 훅을 사용자 전역 설정(`~/.claude/settings.json`)에 등록합니다. 그래서 다른 프로젝트 세션도 알림을 보냅니다. 기존 설정은 `settings.json.voxcode.bak`로 백업됩니다.
2. 상주 리스너(`voice/listener.py`)를 띄웁니다.
3. 판단을 돕는 하이쿠(Haiku) 서브 관리자 창을 띄웁니다. **켜 둔 동안 Claude 사용량이 듭니다.** 원하지 않으면 `/voice-on` 대신 `.venv\Scripts\python.exe -m voice.control on --no-manager`로 켭니다.

`/voice-off`는 등록한 훅만 지우고(다른 훅은 그대로), 리스너와 관리자 창을 닫습니다.

## 이렇게 말하면 됩니다

"자비스"라고 부른 뒤 말합니다. 끝에 삑 한 번이면 접수, **두 번이면 아무 데도 안 보냄**(다시 말하면 됩니다).

| 말 (예) | 결과 |
|---|---|
| "번개장터 봇에 키워드 알림 추가해" | 그 프로젝트에만 전달 |
| "축구 앱 멈춰" | 그 세션에 전달하고 "멈춤"으로 표시 |
| "전부 멈춰" | 모든 세션에 전달 |
| "축구 앱 다시 시작해" | 멈춤을 풀고 전달 |
| "다들 커밋하고 정리해" | 보낼 곳을 확인하고 → "응"이면 전달, "아니"면 취소 |
| "번개장터 어떻게 됐어?" | 그 프로젝트의 마지막 요약을 읽어 줌 |
| "나 없는 동안 뭐 했어?" | 밀린 소식을 읽어 줌 |
| "뭐 열려 있어?" | 열린 프로젝트 목록 |
| "다시 말해줘" | 방금 읽은 것을 다시 읽음 |
| "조용히 해" / "다 알려줘" | 권한 요청만 읽기 / 다시 전부 읽기 |
| "아니야 취소" | 버림 (삑 두 번) |
| "대기" | 아무 데도 안 보내고 다시 호출어를 기다림 (삑 두 번). Jev 키 없이도 동작 |

**대상이 애매한 "멈춰"는 아무것도 멈추지 않습니다** — 잘못 멈추는 것보다 다시 말하는 쪽이 안전해서입니다.

## 명령 판단 (Jev)

받아쓴 문장이 "어떤 명령인지, 어느 프로젝트에 하는 말인지"를 TypeSafe의 판단 모델 Jev가 정합니다.
프로젝트 폴더의 `.env`에 키를 넣으면 켜집니다.

```
TYPESAFE_API_KEY=<키>
```

판단 순서: 규칙 → Jev(확신도 0.8 이상만 채택) → 하이쿠 서브 관리자 → 기본 규칙.

**키가 없으면** 위 표의 명령 대부분이 동작하지 않고 이렇게만 됩니다:
- 말한 내용을 "방금 알림 온 프로젝트"로 보냅니다.
- "멈춰"는 열린 세션이 하나일 때만 멈춥니다.
- "(음악)"처럼 괄호로 감싼 받아쓰기 잡음은 버립니다.

**키를 넣으면 밖으로 나가는 데이터** (TypeSafe 서버, 미국):
- 말할 때마다: 받아쓴 문장, 열린 프로젝트의 폴더 이름, 각 프로젝트의 마지막 요약(최대 300자)
- 알림이 올 때마다: 모든 프로젝트 세션의 완료·권한 알림 문구(최대 300자). 종류(완료·실패·질문·진행 중)를 분류해 기록만 하고, 읽기 동작에는 아직 쓰지 않습니다.
- 세션 연결 정보(소켓 경로·토큰)는 보내지 않습니다.

원치 않으면 키를 넣지 마세요.

## 로드맵

- 실제 마이크와 여러 세션으로 전체 흐름 확인, `log.jsonl`을 보고 확신도 기준(0.8) 조정

- 영어 폴더 이름을 한국어로 부를 별명
