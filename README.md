# Voxcode

화면을 보지 않고도 **여러 프로젝트의 Claude Code 세션을 음성으로 동시에 지휘**할 수 있게
해주는 애드온입니다. 사용자가 다른 일을 하는 동안 상주 프로세스 하나가 여러 세션의 완료
알림을 순서대로 음성으로 안내하고, 음성 명령을 올바른 세션으로 라우팅합니다.

GitHub: https://github.com/PHM820/Voxcode (구 이름: eyes-free-coding)

> **접근성은 이 프로젝트의 부분집합입니다, 목적 자체가 아닙니다.** 기본 가치는 "화면 없이
> 여러 프로젝트를 음성으로 지휘하는 비서"이고, 눈이 안 좋은 사용자를 위한 접근성 도구로도
> 자연스럽게 쓸 수 있는 것이 그 결과입니다 (2026-09-26 재정의, 자세한 경위는
> [`docs/decisions.md`](docs/decisions.md) 참고).

## 무엇을 더하는가

Claude Code에는 이미 공식 <a href="https://code.claude.com/docs/en/accessibility">스크린리더
모드</a>(`--ax-screen-reader`)와 터미널 벨 알림이 있습니다. 이 프로젝트는 그 기능들을
**다시 만들지 않고** 그 위에 훅(hook)으로 얹어, 공식 기능이 아직 하지 않는 두 가지만
새로 더합니다.

1. **완료 음성 요약 (TTS)** — 작업이 끝나면 "무슨 일이 있었는지"를 짧은 한국어 음성으로
   요약해 들려줍니다. 여러 세션이 동시에 끝나면 "{프로젝트명}, {내용}" 형식으로 순서대로
   순차 안내합니다.
2. **음성 명령 입력 (STT)** — 텍스트 대신 음성으로 Claude Code에 지시를 내립니다. 호출어를
   말하면 받아쓰기 모드로 들어가고, 인식된 텍스트가 올바른 세션에 자동으로 전달됩니다.

## 설치

> **정직하게 밝힙니다**: 설치 스크립트 실행과 `/voice-on` 최초 온보딩(언어·목소리 선택)
> 자체는 텍스트 기반이라 화면 확인이 필요합니다 — 이 단계는 기존 스크린리더(NVDA 등)나
> 다른 사람의 도움으로 진행하는 걸 전제로 합니다. 이 프로젝트가 새로 더하는 "화면 없이"는
> **온보딩이 끝난 이후**부터입니다.

```
setup.cmd
```

프로젝트 루트에서 이 스크립트 하나만 실행하면 끝입니다. 하는 일: Python 가상환경(`.venv`)
생성 → `requirements.txt` 설치 → 한국어 TTS 모델(약 64MB)과 whisper.cpp STT 모델(약
147MB)을 `models/`에 자동 다운로드.

**SSL 인증서 에러**(`CERTIFICATE_VERIFY_FAILED`, `SSLCertVerificationError` 등)가 나면
백신(Kaspersky, ESET, Avast, ZScaler, Netskope 등)의 SSL 검사 기능이 원인일 가능성이 높습니다.
해결 절차는 [`docs/known-issues.md`의 1번 항목](docs/known-issues.md#1-pip-ssl-인증서-검증-실패-백신-ssl-검사-소프트웨어-사용자-전원-영향-가능)을
그대로 따라 하면 됩니다(가상환경 안 파일만 수정하는 방식이라 시스템 전체에는 영향 없음).

설치 후 아래로 제대로 설치됐는지 확인할 수 있습니다.

```
.claude\verify.cmd
```

음성 명령을 쓰려면 호출어("자비스")를 본인 목소리로 한 번 녹음해야 합니다(4번, 한 번에 2초).
프로젝트 루트의 터미널에서 실행하고, 안내가 나올 때마다 Enter를 누른 뒤 말하면 됩니다.
녹음 전에도 완료 음성 요약은 동작합니다.

```
.venv\Scripts\python.exe -m voice.wakeword onboard
```

그다음 Claude Code에서 `/voice-on`으로 켭니다(처음이면 언어·목소리를 고릅니다).

### 선택: 음성 명령 판단 (Jev)

TypeSafe의 판단 모델 Jev API 키를 프로젝트 루트 `.env`에 넣으면, 받아쓴 문장마다 "무슨 명령인지"
(지시·멈춰·전체 멈춰·다시 시작·취소·잡음)와 "어느 프로젝트에 하는 말인지"를 판단합니다.
"번개장터 멈춰"처럼 한국어로 프로젝트를 부를 수 있고, whisper가 잡음에서 지어낸 문장도 버립니다.

```
TYPESAFE_API_KEY=<키>
```

- 키를 넣으면 **받아쓴 문장, 열린 프로젝트의 폴더 이름, 각 프로젝트의 마지막 완료 요약(최대 300자)이
  TypeSafe 서버(미국)로 전송**됩니다. 원치 않으면 키를 넣지 마세요. 세션 연결 정보(소켓 경로·토큰)는 보내지 않습니다.
- 키가 없거나 판단이 확실하지 않으면 "방금 알림 온 프로젝트"로 보냅니다. 단, "멈춰"는 대상이 확실하지 않으면
  아무것도 멈추지 않습니다. 괄호로 감싼 표기("(음악)" 등)는 키가 없어도 내 컴퓨터 안에서 걸러집니다.
- 음성모드가 켜져 있는 동안 **모든 프로젝트 세션의 완료·권한 알림 문구(최대 300자)도 종류 분류(완료/실패/질문/진행 중)를 위해
  TypeSafe로 전송**됩니다 — 말하지 않아도 알림이 올 때마다입니다. 지금은 기록만 하고 읽기 동작에는 쓰지 않습니다.
- 버리거나 대상이 애매하면 끝 비프가 두 번 울립니다(한 번 = 접수, 두 번 = 아무 데도 안 보냄 — 다시 말하면 됩니다).
- 말한 내용과 판단 결과는 `~/.voxcode/log.jsonl`에 기록됩니다(내 컴퓨터 안).

## 요구 사항

- Windows (1차 지원 — macOS/Linux는 추후 고려)
- Python 3.12 이상
- Node.js (`voice/inject.js` 실행용)

## 지금 상태 (2026-11-20)

과장하지 않기 위해 "코드와 자동 검사까지 됨"과 "실제로 써 보며 확인함"을 나눠 적었습니다.

**실제로 확인한 것**
- 완료 음성 요약: Stop 훅 → 리스너 → "{프로젝트명}, {요약}" TTS 재생.
- 입력 주입(`voice/inject.js`): Claude Code 공식 세션 메시지 소켓으로 세션에 말 넣기.
- 판단기(Jev)가 "번개장터 멈춰", "전부 멈춰", "다시 시작해", 잡음 문장을 맞게 판단(실제 호출 4건).
- 설치 스크립트(`setup.cmd`).

**코드와 자동 검사까지 됨 (실제 마이크·실제 여러 세션으로는 아직 확인 전)**
- 음성 명령: 호출어 "자비스" → 받아쓰기 → 판단(규칙 → Jev → 하이쿠 서브 관리자) → 해당 세션에 전달.
  지시·멈춰·전체 멈춰·다시 시작·전체 지시(확인 후)·상황 묻기·밀린 거 듣기·다시 말해줘·목록·조용히·취소.
- 기록: 말한 내용과 판단 결과를 `~/.voxcode/log.jsonl`에 먼저 기록한 뒤 전달.
- 여러 프로젝트: `/voice-on`이 훅을 사용자 전역 설정에 등록(끄면 해제)해서 모든 프로젝트 세션이 알림을 보냄.
- 훅 → 리스너 전달은 파일(`~/.voxcode/inbox/`) — 리스너가 꺼져 있어도 알림이 사라지지 않음.

## 로드맵

- 실제 마이크·여러 프로젝트 세션으로 전체 흐름 확인, `log.jsonl`로 판단 기준선(0.8) 조정.
- 알림 종류 판단(완료/실패/질문)을 1주 기록해 보고, 규칙보다 나으면 조용히 모드의 읽기 기준으로 적용.
- 서브 관리자 세션의 대화가 쌓일 때 비우는 방법(재시작 주기).

각 항목의 최신 진행 상태는 [`CLAUDE_MAP.md`](CLAUDE_MAP.md)의 "기능별 파일" 표에서 확인하는
것이 가장 정확합니다(이 README보다 더 자주 갱신됩니다).
